# Android-статус r367

Создан единый Android/H700 исходный проект. Android APK ещё не собран (нет Android SDK/NDK в локальном окружении). GitHub Actions может собрать ARM64 debug APK с синтезированными ресурсами. Для личной сборки с оригинальной музыкой используйте `scripts/bundle_personal_assets.py`. Локальные EXE и MUSIC не публикуются в открытой GitHub-ветке.
