# AirXonix r369 — Android ARM64 (самодостаточный APK)

## Что это

Android-проект на базе восстановленного исходного кода AirXonix r369. Он **создаёт** APK с ARM64 `libmain.so`, SDL2 2.30.12, OpenGL ES2 и полностью встроенными ресурсами. Windows EXE **не запускается**: он включён только как источник оригинальных изображений/таблиц ресурсов. Сюда включены исходные **оригинальные 11 файлов MUSIC**, ранее предоставленные владельцем игры, и резервный clean-room resource pack.

Для игры НЕ требуется отдельное копирование папки `MUSIC`, EXE или архива. При первом запуске приложение извлекает эти файлы из собственного APK во внутреннюю папку приложения (в рамках Android sandbox). `gameinf.bin` и `hscore.bin` сохраняются после обновлений. Интернет и доступ к общей памяти телефона не требуются.

## Как собрать APK

Требуется Android Studio или Linux/Windows c JDK 17, Android SDK Platform 35, Android NDK, CMake 3.22.1, Git и Gradle 8.7 (Android Gradle Plugin 8.6.1). Устройству нужен Android 8.0+ и ARM64.

1. Запусти `bash scripts/prepare_sdl2.sh` (один раз скачает официальный SDL2 2.30.12 и его **совпадающие по версии** Java-модули).
2. Открой корень проекта в Android Studio и запусти **Build APK(s)**; либо выполни `gradle :app:assembleDebug`.
3. Полученный APK: `app/build/outputs/apk/debug/app-debug.apk`.
4. Установи APK на Android 8+ (ARM64). Игра запускается без внешних файлов.

Есть и GitHub Actions `.github/workflows/android-apk.yml`: после загрузки проекта в собственный репозиторий GitHub запусти workflow `Build AirXonix Android APK`, скачай сформированный артефакт APK. В этом варианте локально Android SDK не требуется.

## Управление

- Сенсорный аналоговый стик внизу слева (с 20% мёртвой зоной, движение по доминирующей оси), **A / B** справа, **пауза** справа сверху. Одновременное нажатие двумя пальцами поддерживается.
- Bluetooth/USB-геймпады обрабатываются SDL2 GameController.
- Вибрация при потере жизни реализована через системный Android Vibrator; по умолчанию 82% и 260 мс. Изменение стандартных значений возможно в коде или через существующие параметры окружения.
- Соотношение сторон игры остаётся 4:3. На широких экранах сохраняются чёрные боковые поля.

## Техническая архитектура

- `native/` — полный исходный код r369, core, renderer, audio, 3D-меню и тесты.
- `app/src/main/assets/` — встроенные original EXE/MUSIC и совместимый clean-room ZIP.
- `app/src/main/java/com/airxonix/nativeport/` — SDL Activity, атомарная распаковка, сенсорное управление, haptic.
- `scripts/prepare_sdl2.sh` — официальный SDL2 Android JNI/Java bridge строго одной версии.
- Android CMake: собирает `libmain.so` вместо Linux ELF `airxonix`; `AIRXONIX_NO_PNG` использует оригинальные TGA и встроенный ресурсный слой.
- JNI mask для сенсорных кнопок объединяется с обычным `InputSystem`, не ломая PC/PortMaster-ветку.

## Текущая валидация

Проект собран на базе сохранённого r367; исходные clean-room ZIP / original EXE / original MUSIC включены. **Фактическая компиляция Android APK и его запуск на телефоне пока не подтверждены в текущем окружении**: отсутствуют Android SDK/NDK/Gradle и внешний доступ к их загрузке. Сборочные файлы подготовлены для Android Studio/GitHub Actions. Это не APK-файл и не гарантия запуска без доработок, пока не выполнена реальная Android-сборка и тест на устройстве.

Лог после запуска: `adb logcat -s AirXonixAndroid SDL` или `adb logcat | grep -i AX_BOOT`.

**Важно:** оригинальные EXE и MUSIC, включённые в архив из предоставленной пользователем копии, предназначены для личной сборки. Для публичной публикации исходников и APK с этими ресурсами требуются права на их распространение; GitHub-репозиторий с ними рекомендуется создавать приватным.


## Исправления Android r368
- Клавиатура открывается только при вводе имени для таблицы рекордов и закрывается после подтверждения/отмены.
- D-Pad заменён на виртуальный аналоговый стик; движение выбирается по доминирующей оси, так как оригинальная игра двигается строго по четырём направлениям.
- A подтверждает, B отменяет; во время игры B открывает подтверждение возврата в меню, где A подтверждает, B отменяет.
- Мультитач: удерживание стика + нажатие кнопок A/B одновременно.

Подтверждённые изменения r369 см. [CHANGELOG_R369_RU.md](CHANGELOG_R369_RU.md).
