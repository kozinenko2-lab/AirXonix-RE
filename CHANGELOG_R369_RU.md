# AirXonix Android r369 — исправления меню и значка

- Значок: выбранная пользователем первая иллюстрация AIR XONIX, с ресурсами mipmap и Android Adaptive Icon.
- JNI сохраняет короткие импульсы A/B и направления даже между двумя игровыми кадрами.
- В меню стик выдаёт один навигационный шаг, затем повторы через 340 мс / 145 мс; в игре движение осталось непрерывным.
- Главное меню сбрасывает блокировку на отпускании во время перемещения выбора.
- Выбор режима сразу принимает первый новый ввод после завершения открытия экрана.
- Добавлены тесты test_android_menu_r369 и test_android_touch_pulses_r369.
- Linux PortMaster H700 не получает Android-специфичные изменения ввода; общая логика меню исправлена.

Публичный архив не содержит original EXE/MUSIC; личный архив содержит их.
Android SDK/NDK необходим для сборки APK.
