# AirXonix r386 — Wi-Fi мультиплеер внутри игры

**Цель:** две консоли Anbernic RG40XX H (или совместимые Linux/PortMaster), подключённые к одной Wi-Fi сети, без ручного ввода IP и второго лаунчера.

## Запуск

1. Установите **один и тот же** пакет r386 на обе консоли. Запускайте `AirXonix.sh`.
2. На первой консоли в главном меню выберите **МУЛЬТИПЛЕЕР → HOST**.
3. На второй консоли выберите **МУЛЬТИПЛЕЕР → JOIN**.
4. Вторая консоль прослушивает UDP-маяки и автоматически подключается к хосту по TCP. После подтверждения протокола игра начинается на обеих консолях.

Внутри меню работают крестовина, A (подтверждение) и B (отмена). Во время поиска B отменяет поиск/ожидание. Во время сетевой игры удерживайте **B + Select 1,2 секунды**, чтобы выйти в главное меню. Старая отдельная `AirXonix Multiplayer.sh` не требуется; перед установкой удалите её из старого порта, если она сохранилась.

## Сеть

- TCP-порт по умолчанию: `27840`. Его можно изменить переменной `AIRXONIX_MP_PORT` в `AirXonix.sh`.
- UDP-порт обнаружения: `27841`. Host рассылает маячки с версией протокола и своим TCP-портом; Join выбирает совместимый хост и подключается.
- Для совместимости обе консоли должны использовать одну и ту же версию r386 и находиться в одной IPv4 сети (Wi-Fi/router/hotspot). Отключите Wi-Fi client/AP isolation; разрешите UDP 27841 и TCP 27840 (или выбранный порт) в firewall.
- При потере связи игра останавливает симуляцию, а клиент пробует переподключиться к прежнему адресу. Если соединение ещё не установлено, B отменяет поиск.
- Если в сети несколько хостов, Join присоединяется к первому найденному совместимому хосту. Список серверов пока не предусмотрен.

## Файлы

- `AirXonix.sh` — единый PortMaster launcher.
- `AirXonix/airxonix` — ARMHF ELF для H700 (OpenGL ES2 / SDL2).
- `AirXonix/AirXonix-cleanroom.zip` — полностью генерируемые ресурсы, включая `textures/M105.tga` и `textures/MPMENU.tga`.
- `AirXonix/libs-armhf/` — распространяемые системные C++/SDL-библиотеки. GLES2 предоставляется прошивкой.
- `AirXonix/logs/AirXonix.log` — журнал запуска в каталоге игры.

Условия запуска: прошивка должна предоставлять `/lib/ld-linux-armhf.so.3` (ARMHF compatibility) и работающий драйвер GLES2. Если этого нет, бинарник не запустится; это не устраняется настройкой сети.
