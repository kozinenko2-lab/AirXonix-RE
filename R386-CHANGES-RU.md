# r386 — внутриигровой Wi-Fi мультиплеер

- Новый шестой пункт МУЛЬТИПЛЕЕР в главном 3D-меню, с исправленной компоновкой строк и указателя.
- Новый экран HOST / JOIN / BACK с настоящим TGA-атласом `MPMENU` и строками состояния.
- UDP-обнаружение IPv4 LAN, включая broadcast интерфейсов и сверку версии протокола. TCP-соединение по обнаруженному адресу/порту.
- Управление сетью из основного игрового цикла вместо переменных отдельного лаунчера.
- Отмена и повторный поиск, переподключение после разрыва, возврат в главное меню по B + Select.
- Новые TGA `M105`, `MPMENU` внутри `AirXonix-cleanroom.zip` и обновлённая генерация атласа главного меню.
- Один `AirXonix.sh` для одиночной и сетевой игры, журналы внутри каталога игры.
- Целевые тесты пройдены локально, ARMHF сборка успешна. Аппаратная проверка на двух H700 остаётся необходимой.
