# r388 — Дополнительные бонусы AirXonix

## Один переключатель

В **Настройках** появился пункт **НОВЫЕ БОНУСЫ: ДА / НЕТ** (над оригинальными строками, ниже «Жизни» и «Время»).
Включается крестовиной Влево/Вправо либо кнопкой A. По умолчанию — **НЕТ**.

- **НЕТ**: оригинальная шестёрка бонусов, оригинальный генератор `?`, оригинальная последовательность MSVC `rand()`; никаких новых игровых эффектов.
- **ДА**: дополнительно появляется один новый бонус на поле с собственным таймером; также оригинальный `?` может выдавать любой из пяти новых бонусов с вероятностью 5/12 (оставшиеся 7/12 — прежнее поведение `?`). Отдельной опции для `?` нет.
- Настройка сохраняется в `gameinf.bin.bonuses.ini` (число 0/1), рядом с **неизменённым 36-байтным** `gameinf.bin`.

## Типы и действия

| Бонус | Механика | Длительность |
|---|---|---|
| Щит | Поглощает один смертельный контакт; не расходует жизнь | До удара или 12 секунд |
| Снежинка | Замораживает движение наземных, летающих врагов и особых объектов | 6,5 секунды |
| Две жизни | Немедленно +2 общих жизни, не более 99 | Мгновенно |
| Очки ×2 | Удвоение очков за захваченные клетки и бонус +1000 | 15 секунд |
| Безопасный хвост | След Xonix защищён от атак и опасных контактов с ним | 8 секунд |

В кооперативе награды и временные эффекты общие; хост принимает все решения, клиент получает состояние в AXMP **v8**. Обе консоли должны использовать r388.

## Clean-room ресурсы

В `AirXonix-cleanroom.zip` добавлены **пять** простых 3D-моделей `models/bonus_models.axbm` (AXBM v1) и текстурный атлас `textures/BONUSX.tga` (256×256). В игре они загружаются через существующий `CleanroomArchive`, **независимо от наличия оригинального EXE**. Оригинальный `?` не перерисован.

Генератор `tools/generate_bonus_models.py` использует примитивные low-poly контуры/спицы/пластины с небольшой экструзией и заново создаваемую текстуру; форма сердца получена из контура ранее восстановленной оригинальной процедуры. Права на оригинальную игру сохраняются за правообладателями.

### Пересборка clean-room архива

```sh
python3 -m pip install numpy pillow
python3 tools/generate_cleanroom_resources.py ./assets-r388
# Образуется ./AirXonix-cleanroom.zip
```

### Проверки

- Сборка ARMHF H700 с clang17/Sysroot: проходит, ARMv7 hard-float ELF.
- r388-проверка настроек, моделей, эффектов, сетевого снимка: проходит.
- 8 существующих LAN-тестов: проходят (всего 9/9 в целевом наборе).
- Проверка работы на двух физических Anbernic RG40XX H: ещё не проводилась.

Важно: при включении расширенных бонусов это **модифицированный игровой режим**, а не утверждение о поведении исходного AirXonix EXE. Для точного сравнения с оригиналом оставьте настройку «Нет».
