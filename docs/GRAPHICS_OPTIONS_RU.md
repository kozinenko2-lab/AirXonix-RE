# План отключаемых графических улучшений (H700 / OpenGL ES 2.0)

**Статус:** рекомендации; переключатели ниже ещё НЕ реализованы. Вариант **Original** всегда должен оставаться умолчанием, с неизменной логикой одиночной игры.

## Рекомендуемые режимы

| Режим | Эффект | Нагрузка для H700 / GLES2 | Очерёдность |
|---|---|---|---|
| Original | Оригинальные цвета, освещение и фильтрация без постобработки | Исходная | По умолчанию |
| Sharp | Чёткие пиксели у некоторых текстур и интерфейса (селективный `GL_NEAREST`), без дорогостоящих фильтров | Минимальная | Первым |
| Enhanced | Лёгкая коррекция гаммы/насыщенности + более выразительные блики/тени в текущем фрагментном шейдере | Малая | Вторым |
| Toon / Cel shading | Квантование **существующего `vLight`** на 3–4 полосы света, необязательное усиление контраста | Малая или умеренная | Третьим |
| FXAA | Однопроходное сглаживание через отдельный FBO; требуется проверить драйвер, память и FPS | Умеренная, иногда высокая | Экспериментально |

### Как сохранить совместимость

1. Добавить параметр `Graphics style: Original / Sharp / Enhanced / Toon` в Settings на **каждой** консоли. Значение хранить локально в отдельном файле, не меняя оригинальные структуры `gameinf.bin`.
2. Не включать ни один фильтр по умолчанию. Изменять только визуальную часть рендера; игровое поле, столкновения, таймеры и сетевой протокол от этого не зависят.
3. Применять Toon-квантование только к **3D-объектам**, не к тексту, HUD, меню, изображению жизни и времени. Сейчас исходный шейдер получает готовый коэффициент освещения `vLight`: `toonLight = floor(clamp(vLight,0.0,1.0)*3.0+0.5)/3.0`.
4. Контурный toon-shading через глубину и нормали не брать в первую итерацию: GLES2 потребует дополнительных проходов/FBO, что слишком дорого для Allwinner H700 и 1 ГБ памяти.
5. Переключать стиль можно сразу или на следующем кадре; при ошибке компиляции GLSL автоматически возвращаться к Original и писать диагностику в лог игрового каталога.
6. Проверять 30/60 FPS на реальном RG40XX H, особенно в сценах с большим числом следов и врагов; отключить FXAA автоматически при нехватке видеопамяти или низком FPS.

**Приоритет:** сначала селективная чёткость текстур и Toon по существующему освещению — оба эффекта обходятся без дополнительных полноэкранных проходов. На OpenGL ES2 это значительно реалистичнее, чем полноценные контуры, SSAO, bloom с несколькими FBO и тяжёлая постобработка.
