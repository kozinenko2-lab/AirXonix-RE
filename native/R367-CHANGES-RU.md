# AirXonix r367 — точечные исправления

- `src/game/entities.hpp`: вспомогательные координаты отображения кроуллера при `respawnDelay > 0`. Кэш оригинального 28-байтового объекта и игровые коллизии не затронуты.
- `src/render/renderer.cpp`: положение тела, двух проекций на поле и блика используют согласованную точку появления до приземления.
- `src/game/game.cpp`: оригинальные пункты настроек 0–5 остаются без изменений, модифицированные 6/7 отображаются наверху, без движения камеры за конец меню. Навигация: 0 ВВЕРХ -> 7 ВВЕРХ -> 6; 6 ВНИЗ -> 7 ВНИЗ -> 0.
- `src/main.cpp`, `portmaster/AirXonix.sh`: по умолчанию вибрация 82%, 260 мс; обе величины настраиваемы.
- `tests/test_port_fixes_r367.cpp`: тест логики навигации, визуальной непрерывности координат, экрана 3D-логотипа и параметров вибрации.
- Исходные формулы модели, поворотов и положения логотипа оставлены нетронутыми после 11 точек проекционного аудита. Не следует подменять их не подтверждёнными поправками без скриншота из RG40XX H и сопоставления с EXE.

Сборка AArch64 выполнена Clang 17 + LLD; на целевой консоли НЕ проверена.
