# r381–r385: стабилизация сетевого кооператива

- AXMP v7: байт состояния общей паузы хоста, проверка значения на приёме.
- START на любой консоли переключает паузу по фронту кнопки. Удержание, двойное нажатие и одновременное нажатие проверены.
- `coopLinkReady` показывает WAITING/CONNECTING после обрыва связи.
- События смерти дают вибрацию **только владельцу погибшего Xonix**; общий счёт жизней не вызывает вибрацию на чужой консоли.
- Клиент инициализирует Game Over визуализацию при переходе из обычной игры.
- Удержание B+SELECT 1,2 секунды завершает только выделенную multiplayer-сессию.
- Девять LAN тестов пройдены; два новых интеграционных теста также под ASan/UBSan.
- Полная сборка ARMHF `airxonix_mp` (ARMv7-A, NEON, hard-float) с Clang17/SDL2/GLES2; glibc и ABI проверены readelf.
- Физическое тестирование двух консолей и прохождение всей кампании по Wi-Fi не проводились.
- r385: `GAME_MODE=0..4` в лаунчере выбирает один из пяти оригинальных игровых режимов; при повторном запуске сохраняется режим хоста.
