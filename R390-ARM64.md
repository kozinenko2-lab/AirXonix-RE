# AirXonix r390 — native ARM64

Primary target: AArch64 (ARMv8-A, Cortex-A53) for Allwinner H700, compiled from our own reverse-engineered C++ source. ARMHF remains optional. Use scripts/build_h700_arm64.sh with the PortMaster-H700-SYSROOT.

The cross-build uses Clang/LLD and builds an ELF64 binary linked to SDL2 and firmware-provided GLES2. The available AArch64 SDL2/libstdc++/libgcc_s libraries require glibc 2.38 and may not work on older firmware. The GLES2 stub is build-time only and must not be redistributed. On-device testing is outstanding.
